## 결과와 추가 구현의 기여

- 최초 29회차의 쾌속/균형 58개 계획: 운영판 대비 시간 단축 54개·동일 4개, 시간/출항 수 악화 0개.
- 앞서 보고한 1차 후보 대비: 한 개발 회차의 쾌속/균형에서 각각 6→5출항, 각 약 29.16초 추가 단축. 나머지 56개 계획은 1차 후보와 동일.
- 3출항 동시 재배치를 켜고 끈 실험으로 위 추가 감소의 원인을 확인했다. 혼합 병합은 이번 29회차에서 추가 이득이 없었으나 독립 합성 경계 사례에서 단순 연결보다 나은 병합 경로를 생성함을 확인했다. 합성 효과를 실사용 개선 횟수로 세지 않았다.
- 고정 검증 9회차/18개 계획은 17개 단축·1개 동일. 계획당 단축 중앙값 386.58초, 합산 예상시간 3.41% 감소. 이는 운영판 대비이며 1차 후보 대비 추가 개선은 검증군에서 0이다.
- 추가 재계산 포함 39기록/78개 모드에서 교환 결과·재고·교섭력·6/7단 항로 보존과 재고/무게 검산 통과.
- 9회차는 1차 후보에서 이미 결과를 열람한 고정 검증군이다. 최종 후보를 조정한 자료는 개발군이며 이번 9회차 결과를 새로 수집한 미열람 실사 평가로 표현하지 않는다. 신규 실사 검증은 미실행이다.
